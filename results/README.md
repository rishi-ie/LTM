# Experimental Results

This directory contains one canonical measured run per completed phase.

| Directory | Experiment |
| --- | --- |
| `phase-1/` | Single-state semantic-field comparison |
| `phase-1.1/` | Multi-state semantic optimization |
| `phase-1.2/` | Hierarchical semantic equilibrium |

Quality metrics, selected configurations, suite and corpus hashes, evidence
IDs, energy diagnostics, and classifications are reproducibility-critical.
Latency, process RSS, timestamps, and run IDs may vary by machine.

Reproduction commands and interpretation are documented in
[`docs/report.md`](../docs/report.md). Temporary reruns belong under
`results/tmp/` and are ignored.
