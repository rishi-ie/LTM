# Fresh LTM Architecture Viability Audit Specification

`LTM-A2` is a read-only audit of the current LTM architecture. It replays the
universal Mumbrane representation against its independent semantic-body oracle,
checks documented experiment boundaries against implementation, and reports two
verdicts: controlled LTM v1 viability and unrestricted/full-vision viability.

It does not train a model, create a new locked experiment, or reclassify a
historical result. Its generated report is stored beside this specification.
