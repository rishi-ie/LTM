# LTM v1 Build Plan

Normative architecture: [LTM-ARCH-1.1](../architecture/architecture-lock-v1.md).

## Current starting point

Use G2.14 as the supplied-span conversational route and G2.5 as the provisional
reasoning route. Both target Mumbrane IR v1, with G1 as exact topology authority
and FieldIR v2 as the verified packed execution bridge. G3–G14 remain controlled
component evidence. Do not modify historical experiment packages.

## Build order

1. Promote the isolated Mumbrane schema/codec into `src/ltm/` without changing
   the proven G1 or FieldIR v2 contracts.
2. Make FieldIR v2 a derived packed execution view of Mumbrane IR.
3. Add the four compiled topology profiles and tiered migration policy.
4. Point G2.14 conversation events and G2.5 controlled reasoning proposals at
   the same atomic Mumbrane construction boundary; require preview or
   confirmation for the provisional reasoning path.
5. Use the validated numeric views for G3–G9.
6. Use G10.1 authorized response realization and archive-label validation.
7. Move G11 clearable session state and G12 persistence to universal units.
8. Re-run G13 scale and G14 composition over the promoted packed codec.
9. Run G15 serving, isolation, crash recovery and operational fault testing.
10. Run L2 as a separate ordinary-math compiler gate; do not fold compiler
    errors into proof-search measurements.

## First vertical slice

The first user-visible slice accepts a supplied-span G2.14 conversational turn
or an explicitly confirmed reasoning proposal, stores universal Mumbrane units,
applies the selected profile, answers a topology-addressed query with G6/G9
authorization, and realizes the answer through G10.1. It does not claim raw
segmentation or unrestricted chat quality.

## Replacement policy

Compiler, address encoder, topology profile, vector spaces, optimizer and
decoder are replaceable modules behind the Mumbrane contract. FieldIR v2 may be
replaced as an execution encoding only if exact Mumbrane/G1 semantics remain
unchanged. Replacing a module does not rewrite historical experiment results.
