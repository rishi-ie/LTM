# Remaining Product Gaps

The architecture foundation is now defined. The remaining work is product
integration and reliability, not another unbounded sequence of G2 kernel
experiments.

The normative boundary is [LTM-ARCH-1.2](../architecture/architecture-lock-v1.md).

## Current truth

- G1 is the exact topology authority.
- G2 is engineering-complete through two modules: G2.14 passes controlled
  supplied-span conversation routing, while G2.5 remains the provisional
  safety-gated reasoning compiler by explicit engineering waiver.
- LTM-R1 supports a numeric, text-free active field representation.
- G3–G14 provide controlled component evidence.
- G14 is not a raw-language product pass.
- G15 has not run.
- L7 passes the bounded zero-parameter acyclic equilibrium boundary through 20
  body applications; cyclic, scaled and 64-hop equilibrium remain open.
- L8 provides development-only reduced-probe evidence that compiled reasoning
  policy can change an equilibrium without mutating the field; the full suite
  and informal-policy compilation remain open.

## Build gaps

### 1. Canonical FieldIR v2 integration

Complete the numeric codec, source-archive split, vector sidecars, manifests,
semantic/artifact hashes and G1/G2.5 adapters in `src/ltm/`.

### 2. Compiler safety and usability

Use G2.14 for supplied-span controlled conversation events. Use G2.5 only in
controlled or preview/confirmation mode for reasoning until a replacement
proves reliable language grounding. Add or integrate raw semantic segmentation
without weakening atomic insertion, clarification, quarantine or abstention.

### 3. Downstream numeric views

Expose the canonical program to G3 addressing, G4/G5 frontier and coverage,
G6/G7 execution, G8 reduction, and G9 verification without duplicating semantic
state into experiment-specific runtime formats.

### 4. Integrated compiled-topology benchmark

Rerun the controlled G14 panel using topology produced by the compiler rather
than evaluator-supplied gold topology. This is the first meaningful end-to-end
compiler gate.

### 5. Production lifecycle

Run the actual v2 field through G11 session overlays, G12 persistence, and G13
storage scaling. Existing component passes do not automatically prove this
integration.

### 6. G15 serving and isolation

Implement crash recovery, workspace isolation, resource limits, concurrent
session behavior, safe restart, logging and operational fault tests. Until this
is run, the project is not product-ready.

### 7. Mathematical-reality proof search

I3.1 establishes reality-scoped body retrieval, learned action ranking, exact
proof construction and independent replay. L1 observes grounded capacity
through 64 hops, but its formal panel is simple and its 20/20 per-depth Wilson
lower bound is about 83.9%. Treat exact indexed search as the working mechanism
and hierarchical guidance as research. L3 verified indexed 45-step compilation
and replay, while L4 failed before lock on unseen branching proposal selection
(33.3% answerable success and 27.4% proposal recall@16). A replacement proposal
learner must pass goal/scorer/value causal controls before another stress run.

### 8. L2 ordinary mathematical-language compilation

Compile ordinary mathematical statements into exact formal/Mumbrane bodies and
ordinary questions into assumptions and goals. Measure compilation separately
from proof search, and require exact replay. Compilation uncertainty must
clarify or abstain rather than write an uncertified axiom.

### 9. Fixed-law equilibrium scaling

Keep the L7 law frozen while adding cyclic graphs, indexed retrieval, larger
fields and paths through 64 applications. Separately measure retrieval
coverage, fixed-point uniqueness, convergence, contradiction disclosure and
independent solver agreement. Do not infer this capability from L1's distinct
indexed proof-search result.

## Explicitly deferred

- unrestricted raw-language understanding;
- replacing G2.5 with another small-MiniLM kernel without new evidence;
- generic differentiable equilibrium reasoning beyond L7's fixed unlearned law;
- claims that the current I3.1 minimap or cost-to-go head performs general proof planning;
- claims that L1 proves arbitrary 64-hop mathematics;
- fluent free-form decoding beyond G10.1’s constrained boundary;
- claims of universal topology atoms or production 100M-context quality.
