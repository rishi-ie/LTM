# I3.1 — Development Report

No locked classification has been issued.

## Latest development evidence

On 600 held-out, paired-goal, branching proof problems (depth 2–16), the full
content-index method returned 100% exact results, 100% accepted-proof
precision, zero incorrect accepted proofs, 100% exact proof replay and 100%
required-body frontier recall. This is development evidence only.

On the deterministic 200-problem causal control panel:

| Variant | Exactness |
| --- | ---: |
| Full body-backed content-index search | 100.0% |
| Goal removed | 50.5% |
| Learned action scorer removed | 0.0% |
| Initial frontier fixed | 0.0% |
| Remaining-cost head removed | 100.0% |
| Hierarchical minimap only | 0.5% |

The first three interventions show that the goal, learned body-action scorer,
and dynamic reopening of the bounded content-addressed body index are doing
real work in this controlled field. The current hierarchical minimap summaries
are not sufficient on their own: the minimap-only control reaches 0.5%.
Accordingly, I3.1 does not claim a validated hierarchical-minimap mechanism.
The remaining-cost head has no measurable contribution yet. Therefore I3.1 is
not a final latent A*/cost-to-go pass, and locked execution remains
unauthorized until detour and competing-prefix cases make that mechanism a
meaningful causal test.

## Exact standard-algebra substrate

The same exact body kernel now supports variable-matched signed axiom schemas,
not only ground established lemmas. A retrieved two-body proof of
`(5 + 0) × 1 = 5` applies `ring.mul_one` and `ring.add_zero`, then replays
under the standard reality manifest. A counterfactual finite operator profile
where `1 ⊕ 1 = 3` has a distinct signed manifest and is rejected by the
standard-reality runtime.

## Development length diagnostic

A separate, unfrozen 200-case 17–64-hop panel reached 96.0% exactness with
100% accepted-proof precision and replay. This is a traversal result through
generated equality bodies, not evidence of unrestricted mathematical theorem
proving. It is reported only to characterize the current field/search budget;
it cannot substitute for the pending primary control or a locked result.

## Corpus-validity correction

Review found that the current corpus exposes `stage` and `slot` identifiers in
the public terms and that standard-algebra proposal ordering prefers syntactic
reductions. Those choices are useful for bringing up the field/runtime, but
they make a remaining-cost or necessary-detour claim invalid. The next corpus
revision will use opaque alpha-renamed terms, query-independent minimap cells,
multiple viable routes, required temporary expansions and a fixed action/beam
budget. The evaluator alone will compute shortest remaining proof distance for
cost-head training and measurement. Until that revision passes its controls,
the current 17–64 result remains a traversal diagnostic only.
