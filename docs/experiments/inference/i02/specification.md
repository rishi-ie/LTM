# I2 — Multiscale Minimap Latent Dynamic Inference

I2 tests whether supplied atomic Mumbranes can support relation-free latent
inference when a fixed prompt anchor drives a movable 128D state through
hierarchical minimap summaries and dynamically reopened detailed regions.

The runtime receives no G1 relation names, named roles, logical closure, proof
depth, answer IDs, or evaluator paths. It discovers outcome Mumbranes from the
opened field. The prompt anchor is immutable; only the inference vector and
bounded activations move. Minimap cells contain learned semantic prototypes,
low-rank transition sketches, context masks, uncertainty and child links, never
cached transitive closure.

The authoritative claim is limited to supplied Mumbranes and paths through 64
observed bodies. Unconverged or uncovered paths return `incomplete_frontier`.
Every result is soft and emits no factual operation. Raw MiniLM compilation,
G6/G9 authorization and decoding remain outside this experiment.

Research motivation includes [Neural Relational
Inference](https://proceedings.mlr.press/v80/kipf18a.html), [Relational
Potentials](https://proceedings.mlr.press/v202/comas23a.html), [Hopfield
Networks Is All You Need](https://openreview.net/forum?id=tL89RnzIiCd), and
[Compositional Energy-Based
Models](https://proceedings.mlr.press/v202/du23a.html).

The staged commands are implemented by `python -m ltm_inference_i2`. The run
is fail-fast: local body completion and minimap accounting must pass before
deep composition, interventions or naturalistic diagnostics are authorized.
