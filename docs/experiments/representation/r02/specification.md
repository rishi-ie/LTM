# LTM-R2 — Universal Mumbrane Representation and Configurable-Topology Audit

## Objective

LTM-R2 tests whether one numeric `MumbraneUnit` schema can represent content,
operators, named ports, context, provenance, geometry, identity, region and
integrity, while a separately versioned profile selects the active topology
and latent dynamics. It is a representation audit, not a raw-language
compiler experiment.

## Contract

The candidate uses a universal unit table plus uniform port, coordinate and
vector-bundle tables. Exact sparse ports and coordinates remain authoritative.
Vectors may modulate soft geometry only. Source text remains in a separately
hashed archive.

The locked profiles are reasoning, planning, evidence/science and
conversation-memory. Profile changes are tiered: dynamics-only changes reuse
the substrate; structural changes select and migrate affected units; missing
semantics require source recompilation.

## Evaluation

Development uses 256 evaluator-owned semantic bodies. The locked suite uses
1,024 bodies evaluated under four profiles, for 4,096 executions. It includes
384 tiered transitions, 320 attack cases and compatibility preconditions for
G1–G14. The runtime cannot access evaluator gold.

`LTM-R2-A` requires exact packed reload, exact direct-oracle agreement for all
four profiles, deterministic replay, all attacks rejected, correct tiered
migration handling, zero network calls, and the registered resource envelope.

## Boundary

A pass makes Mumbrane IR v1 a valid target representation for a later modular
compiler. It does not claim unrestricted language understanding, a complete
ontology, or a natural conversational decoder.
