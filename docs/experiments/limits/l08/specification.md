# L8 — Compiled Reasoning-Policy Equilibrium

L8 isolates the hypothesis that reasoning instructions can be compiled into a
signed topology-policy sidecar and then affect the latent equilibrium without
changing the factual substrate. The authoritative input is supplied formal
mathematical semantics. Controlled English policy parsing is diagnostic only.

## Boundary

The policy compiler accepts bounded instructions for source multipliers,
source-class requirements, path decay, conjunction mode, conflict margins,
candidate thresholds, source-count requirements, response style and tension or
certificate disclosure. Arbitrary code, direct answer IDs, route tables, exact
outcome activation, and cross-reality overrides are rejected.

The L8 optimizer is unlearned: zero trainable parameters, no checkpoint, no
learned geometry. Prompt assumptions are clamped at one; all other activations
start at zero. Synchronous sweeps repeatedly reduce the fixed factor law.
Positive and negative channels remain separate, source duplicates are
deduplicated, and near-balanced candidates remain alternatives.

Parasite v0.1 is used only for existing structured compilation and packed field
storage. L8 owns the policy registry, optimizer, evaluator and state path.

## Probe design

The first implementation uses one opaque 512-factor-style field per reality,
depth queries at 1, 5, 10 and 20, positive/opposing source classes, a
conjunction factor, policy twins, and controls for no optimization, one sweep,
decisive-body removal and reversed storage order. Public rows contain no
policy, depth, route, required-body or expected-disposition fields. Hidden gold
is scored by `benchmarks/evaluator_worker.py` in a separate process.

## Classification boundary

The reduced probe can demonstrate policy-conditioned equilibrium behavior, but
it is not the complete planned 96-case L8 suite. A full L8 authorization still
requires the larger contradiction, scoped policy, restoration, invalid-policy,
and controlled-text panels described in the planning record.
