# G5 — Certified Coverage, Distant Influence, and Automatic Widening

G5 is the controlled follow-up to G4. It tests whether a request-local frontier can account for distant registered regions using deterministic summaries, widen when a region can alter the symbolic answer or the 32-dimensional equilibrium, and abstain when a valid bound is unavailable.

The locked experiment uses 100,000 typed factors in regions of at most 256 factors and 240 base/twin pairs. It uses an additive strongly convex quadratic field with conservative quantization bounds, an exhaustive symbolic and continuous oracle, exact safety indexes, four maximum widening rounds, and no language model or network access.

Passing establishes only deterministic coverage for this registered field law. It does not repair natural-language compilation, validate arbitrary nonlinear fields, or establish 100-million-token reliability.
