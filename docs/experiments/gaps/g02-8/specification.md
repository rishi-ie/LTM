# G2.8 — Versioned Golden-Atom Structured Topology Compiler

## Question

Can a selectively adapted local MiniLM compile unseen controlled language into
validated G1 topology and synchronized FieldIR factors using a versioned,
G1-derived bank of 18 topology operators?

## Method

Each sentence receives one encoder pass. The compiler retains scores for all
18 operators, grounds typed content candidates, scores named roles and ordered
argument pairs, reconciles complete legal graphs for four cycles, and commits
only an atomically validated G1/FieldIR pair. The continuous coordinate
sidecars guide field geometry; sparse G1 role incidence is the only factual
authority.

The first authoritative boundary is a gold-content locked kernel. It tests
operator, role, direction, context and complete graph recovery without span
extraction. A failure stops the experiment before document, migration, and
downstream claims. Locked language uses split-disjoint entities, constructions,
and relation wording.

## Boundary

A passing result would apply only to unseen controlled language inside AtomBank
v1 and the current G1 ontology. It would not establish unrestricted language
understanding, native latent decoding, or production readiness.
