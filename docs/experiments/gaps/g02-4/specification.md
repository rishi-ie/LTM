# G2.4 — Atom-Vector Topology Language Compiler

G2.4 is a representation-first replacement for the failed direct language
compiler experiments. It keeps G1 as canonical memory while adding a native
mathematical topology program: semantic atom vectors, explicit typed operator
relations, role incidence and an auditable tensor handoff.

The compiler performs one contextual MiniLM pass for each sentence. Learned
atom slots ground several atoms from its token states, match them against a
bounded stored atom bank, enumerate G1-legal relation programs, reconcile the
program with four HRM cycles, and atomically assemble G1 objects.

The experiment is deliberately bounded to unseen controlled language in the
registered G1 ontology. It does not claim arbitrary document understanding,
production atom indexing, native latent decoding or conversational naturalness.

The authoritative implementation plan, gates, diagnostics, controls, freeze
boundary and classifications are maintained with the source package and this
experiment's frozen workspace. No G2.4 conclusion is valid until a distinct
locked evaluation completes.
